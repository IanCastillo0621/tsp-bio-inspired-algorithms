# Data for Algorithms

This folder contains the address data used for the Traveling Salesman Problem (TSP), as well as distance (transition) matrices derived from both the complete dataset and several sub-samples.

## Contents
- `Addresses_Jalisco_Mexico.csv` – Complete list of real-world addresses used in the project.
- `matrices_40.xlsx` – Distance (transition) matrices for a random sub-sample of 40 addresses.
- `matrices_100.xlsx` – Distance (transition) matrices for a random sub-sample of 100 addresses.
- `matrices_150.xlsx` – Distance (transition) matrices for a random sub-sample of 150 addresses.
- `matrices_200.xlsx` – Distance (transition) matrices for a random sub-sample of 200 addresses.
- `matriz_distancias.csv` – Full distance matrix containing all pairwise distances between addresses in the complete dataset.

## Notes
- Each XLSX file contains **10 independent instances** of the same problem size.
- Data corresponds to the **Jalisco TSP instance**.
- Distances are measured in **kilometers**.
