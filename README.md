## English
In this repository, we solve a real-world Traveling Salesman Problem (TSP) using two bio-inspired algorithms, one heuristic algorithm, and one exact approach. The main objective is to highlight the advantages and disadvantages of bio-inspired optimization methods—algorithms inspired by natural and biological processes.

The Traveling Salesman Problem is a classical optimization problem that seeks the shortest possible route that visits a set of cities exactly once and returns to the starting city. In this project, the task consists of finding the shortest route to visit a set of real-life addresses located in the state of Jalisco, Mexico.

The bio-inspired algorithms used in this project are:
- Genetic Algorithm (GA)
- Ant Colony Optimization (ACO)

The heuristic algorithm used is:
- Greedy Nearest Neighbor

The exact solution was obtained using GAMSpy, a licensed optimization modeling framework.

## Français
Dans ce dépôt, nous résolvons un problème du voyageur de commerce (Traveling Salesman Problem, TSP) du monde réel en utilisant deux algorithmes bio-inspirés, un algorithme heuristique et une approche exacte. L’objectif principal est de mettre en évidence les avantages et les inconvénients des méthodes d’optimisation bio-inspirées, c’est-à-dire des algorithmes inspirés de processus naturels et biologiques.

Le problème du voyageur de commerce est un problème classique d’optimisation qui cherche l’itinéraire le plus court possible visitant un ensemble de villes exactement une fois et revenant à la ville de départ. Dans ce projet, la tâche consiste à trouver le chemin le plus court pour visiter un ensemble d’adresses réelles situées dans l’État de Jalisco, au Mexique.

Les algorithmes bio-inspirés utilisés dans ce projet sont :
- Algorithme génétique (GA)
- Optimisation par colonie de fourmis (ACO)

L’algorithme heuristique utilisé est :
- Plus proche voisin (Greedy Nearest Neighbor)

La solution exacte a été obtenue à l’aide de GAMSpy, un framework de modélisation d’optimisation sous licence.
